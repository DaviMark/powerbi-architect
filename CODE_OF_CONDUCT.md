# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolhedor e construtivo; critique ideias, não pessoas; nada de assédio,
discriminação ou exposição de dados alheios.

**Como relatar:** contate o mantenedor ([@DaviMark](https://github.com/DaviMark)) em privado. Os relatos
são tratados com sigilo. O mantenedor pode editar ou remover conteúdo e bloquear participantes que
violem estas regras.
