# Evals

How to measure whether the skill makes a difference:

1. Pick a case from [`cases.md`](cases.md).
2. Run the prompt in a fresh session **without** the skill, then **with** the skill installed.
3. Score each "must" item (0/1) and each "must not" item (0/1). Note tokens/time if you want.
4. Share results in an issue (no real data) — they guide the next version.

A case passes when all **must** items are present and no **must not** item happens.
