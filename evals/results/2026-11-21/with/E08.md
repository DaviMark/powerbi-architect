## Design proposal (Gate 1, for your approval; nothing built yet)

**Questions the model answers (from the briefing)**
1. What share of customers churned in the last 12 months, by segment and regional?
2. How much revenue was lost to churn?

**Source:** SQL Server view `bi.vw_clientes_churn`, import mode, weekly refresh. One-step native SQL partition with `Servidor`/`Banco` parameters.

**Table `Fato Clientes`** (periodic snapshot)
- Grain: **1 row per customer** (to confirm; see question 1).
- Imported columns (6 of 8):

| Column | Use |
|---|---|
| `id_cliente` (integer key) | count of customers |
| `segmento` | slicer/breakdown (low cardinality, stays in the fact as a degenerate dimension) |
| `regional` | slicer/breakdown (same) |
| `data_ultima_compra` (date) | context, "last purchase" |
| `receita_12m` (decimal 18,2) | revenue lost |
| `flag_churn` (0/1) | churn count |

- **Not imported:** `cpf` (personal data, no question needs it), `nome` (free text, personal data, no use in the two questions). If a customer list is requested later, I will use `id_cliente` plus a masked or approved attribute.
- No `Calendario` for now, since both questions are "last 12 months" at a point in time. If you want a churn trend over time, we need monthly snapshots and a date dimension (see question 2).

**SQL sketch (T-SQL)**
```sql
-- @table Fato Clientes
-- @grain 1 linha por cliente
SELECT
    CAST(id_cliente AS INT)            AS [id_cliente],
    CAST(segmento AS NVARCHAR(50))     AS [Segmento],
    CAST(regional AS NVARCHAR(50))     AS [Regional],
    CAST(data_ultima_compra AS DATE)   AS [Data Ultima Compra],
    CAST(receita_12m AS DECIMAL(18,2)) AS [Receita 12m],
    CAST(flag_churn AS TINYINT)        AS [Flag Churn]
FROM bi.vw_clientes_churn
```

**Measures** (`_Medidas`; each with description, format and folder)
- `Clientes` = `DISTINCTCOUNT('Fato Clientes'[id_cliente])` (Contagens)
- `Clientes Churn` = `CALCULATE([Clientes], 'Fato Clientes'[Flag Churn] = 1)` (Contagens)
- `% Churn` = `DIVIDE([Clientes Churn], [Clientes])` (Indicadores, `0.0%`)
- `Receita Perdida` = `CALCULATE(SUM('Fato Clientes'[Receita 12m]), 'Fato Clientes'[Flag Churn] = 1)` (Valores, currency)

**Page wireframe (1 page, 1 question):** "Quanto do nosso cliente estamos perdendo, e onde?". Two KPI cards (% Churn, Receita Perdida), a bar of % Churn by Segmento, a bar by Regional, and a detail table by Regional x Segmento. At most 2 slicers. Documentation page included.

**Security:** classification `internal` or `confidential` (your call). `contains_pii` is false in the model, since I am excluding `cpf` and `nome`. RLS question below.
