These go in the measure table, each built on a base measure, with a description, format and display folder. I assume `Vendas` is related to `Calendario` on `data_pedido` (many to one, single direction) and that `Calendario[Data]` is marked as the date table.

```tmdl
table _Medidas

	/// Total revenue (sum of Receita) in the selected context.
	measure Receita = SUM ( Vendas[Receita] )
		formatString: #,0
		displayFolder: Valores

	/// Total cost (sum of Custo) in the selected context.
	measure Custo = SUM ( Vendas[Custo] )
		formatString: #,0
		displayFolder: Valores

	/// Revenue minus cost.
	measure Margem = [Receita] - [Custo]
		formatString: #,0
		displayFolder: Valores

	/// Number of distinct orders.
	measure Pedidos = DISTINCTCOUNT ( Vendas[id_pedido] )
		formatString: #,0
		displayFolder: Contagens

	/// Margin as a share of revenue: (Receita - Custo) / Receita.
	measure '% Margem' = DIVIDE ( [Margem], [Receita] )
		formatString: 0.0%
		displayFolder: Indicadores

	/// Revenue in the same period of the previous year.
	measure 'Receita AA' = CALCULATE ( [Receita], SAMEPERIODLASTYEAR ( Calendario[Data] ) )
		formatString: #,0
		displayFolder: Tempo

	/// Revenue growth versus the same period last year: (Receita - Receita AA) / Receita AA.
	measure 'Crescimento % AA' = DIVIDE ( [Receita] - [Receita AA], [Receita AA] )
		formatString: +0.0%;-0.0%;0.0%
		displayFolder: Tempo

	/// Average revenue per order: Receita / Pedidos.
	measure 'Ticket Médio' = DIVIDE ( [Receita], [Pedidos] )
		formatString: #,0.00
		displayFolder: Indicadores
```

**Why it is built this way**
- `Receita`, `Custo` and `Pedidos` are the base measures, and the three you asked for only reuse them.
- `DIVIDE` handles zero and blank denominators (no `IFERROR`). I do not turn blanks into zero.
- Because the YoY measure uses the date table, it shows blank where there is no previous-year data.
- Hide `Receita`, `Custo` and `id_pedido` in `Vendas` and set `summarizeBy: none`, so nobody drags raw columns into visuals.
