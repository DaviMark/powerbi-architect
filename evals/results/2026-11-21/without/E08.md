## What I would build

**Source:** `bi.vw_clientes_churn`. Import only `id_cliente, nome, segmento, regional, data_ultima_compra, receita_12m, flag_churn`. `cpf` is excluded in the SQL (explicit column list, no `SELECT *`), so it never reaches the model. `nome` is kept only if the directors need to identify customers; tell me if not and I will drop it too.

Partition (one step, native query, parameters `Servidor` and `Banco`):

```m
let
    Fonte = Value.NativeQuery(
        Sql.Database(Servidor, Banco),
        "SELECT id_cliente, nome, segmento, regional, data_ultima_compra, receita_12m, flag_churn
         FROM bi.vw_clientes_churn",
        null, [EnableFolding = true])
in
    Fonte
```

**Model (TMDL):** one fact at customer grain `Fato Clientes` (id_cliente, data_ultima_compra, receita_12m, flag_churn as 0/1), small dimensions `Dim Segmento` and `Dim Regional` (distinct values, one-to-many, single direction). Since the only date is `data_ultima_compra`, a `Dim Calendario` is only added if you want churn over time (the briefing asks for a 12-month window only, so I would skip it).

**Measures** in `_Medidas`, each with description, format string and display folder:

```dax
Clientes = DISTINCTCOUNT ( 'Fato Clientes'[id_cliente] )
Clientes Churn = CALCULATE ( [Clientes], 'Fato Clientes'[flag_churn] = 1 )
% Churn = DIVIDE ( [Clientes Churn], [Clientes] )                           // 0.0%
Receita Perdida = CALCULATE ( SUM ( 'Fato Clientes'[receita_12m] ), 'Fato Clientes'[flag_churn] = 1 )   // R$ #,0
```

**Report (PBIR):** one page for directors: KPI cards (% churn, receita perdida), bar of % churn by segmento, by regional (or a matrix segmento x regional), slicers for segmento and regional. Weekly refresh, so no real-time requirements.
