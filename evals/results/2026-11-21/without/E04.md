Here are the three measures. I'm assuming `Calendario` is marked as a date table, has a `Date` column, and has an active relationship `Vendas[data_pedido]` -> `Calendario[Date]`.

```DAX
-- Base measures
Receita = SUM ( Vendas[Receita] )
Custo = SUM ( Vendas[Custo] )
Margem = [Receita] - [Custo]
Pedidos = DISTINCTCOUNT ( Vendas[id_pedido] )

-- 1) Margin %
Margem % = DIVIDE ( [Margem], [Receita] )

-- 2) YoY growth (on revenue)
Receita AA = CALCULATE ( [Receita], SAMEPERIODLASTYEAR ( Calendario[Date] ) )
Crescimento YoY % = DIVIDE ( [Receita] - [Receita AA], [Receita AA] )

-- 3) Average ticket
Ticket Medio = DIVIDE ( [Receita], [Pedidos] )
```

Notes and assumptions:
- `DIVIDE` returns blank on zero or blank denominators, so there is no error when the prior year has no sales.
- Ticket average = revenue / distinct orders. If `id_pedido` repeats across lines of the same order, `DISTINCTCOUNT` is the right choice; if each row is one order, `COUNTROWS ( Vendas )` is equivalent and faster.
- YoY is computed on revenue. If you want it on margin or another measure, tell me and I will change it.
- Set format strings: `Margem %` and `Crescimento YoY %` as `0.0%`, `Receita`, `Custo`, `Ticket Medio` as currency. For TMDL, add `formatString: 0.0%` under each measure.
- If `Calendario` is missing dates for the prior year, `SAMEPERIODLASTYEAR` returns blank. It needs a contiguous date range covering full years.
- Please confirm: should "Receita" be net of taxes/returns already, and is the `Custo` column the total cost per row (not unit cost)? If it is unit cost I would use `SUMX ( Vendas, Vendas[Custo] * Vendas[Quantidade] )`.
