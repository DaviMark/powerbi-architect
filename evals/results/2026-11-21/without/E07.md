## What I found

**Power Query (`Vendas`, 14 steps)**
1. `Sql.Database("srv-prod-01","ERP")` is hard-coded: no `Servidor`/`Banco` parameters, and it points at production.
2. Removes 3 columns from `dbo.PedidoItem` after loading everything (31 columns imported). Better to select only the columns needed (allow-list), at the source.
3. `Table.NestedJoin` + expand of `Produto` merges dimension attributes (`categoria`, `marca`) into the fact. This denormalizes the model and the join can break folding. `Produto` is already a separate table in the model, so this is duplication.
4. `Receita` computed in M (`qtd * preco_unit - desconto`) as a column, then summed. Should be a measure (or computed at source).
5. `Text.Trim`/`Text.Proper`, `Replace null -> "Sem marca"`, `Table.Distinct` on `id_item`, and a final `Table.Sort` all break query folding or cost refresh time. The sort has no effect on the model and should be removed. Cleaning belongs in a view or in the dimension.
6. Several steps are redundant (separate rename/type/replace steps).

**Model**
- Auto date/time is on (6 hidden `LocalDateTable_*`): disable it and add a proper `Dim Calendario` marked as date table.
- `Vendas[Ano]` calculated column: replaced by `Dim Calendario[Ano]`.
- Relationship `Vendas -> Cliente` is **bidirectional**: change to single direction (Cliente filters Vendas) unless there is a documented need.
- `Produto` has no relationship from `Vendas` listed (the join was done in M); I will create `Vendas[id_produto] -> Produto[id]`, many-to-one, single.

**Measures** (no descriptions, formats or folders)
- `Margem %` uses `/` instead of `DIVIDE`, risk of division errors. Uses `custo`, which is not in the M steps shown; I need to confirm where it comes from (kept by the 31 columns?) and that `custo` is on the same basis as `Receita` (quantity x unit cost).
- `Vendas AA` uses `SAMEPERIODLASTYEAR(Vendas[Data Pedido].[Date])`, which depends on auto date/time. Moves to `Dim Calendario[Data]`.
- Add descriptions, format strings, display folders; names to our standard.

**Report (3 pages, 41 visuals)**
- 12-slice pie chart: replace with a sorted bar chart (top N + "Outros").
- 9 slicers on page 1: reduce to the few that matter (e.g. period, regional/category) and move the rest to a filter pane or sync them.
- I will review the other 39 visuals page by page.
