# Suporte

- **Como instalar ou usar?** Leia o [README](README.md) ([English](README.en.md)) e, se a dúvida
  continuar, abra uma issue com o formulário **Dúvida**.
- **A IA não seguiu a skill?** Abra uma issue **Comportamento da IA**.
- **Algo quebrado?** Abra uma issue **Bug**.
- **Vulnerabilidade de segurança?** Relate em privado, conforme o [SECURITY.md](SECURITY.md).

English is welcome too. Este é um projeto comunitário mantido no tempo livre: não há prazo de
resposta garantido, mas toda issue é lida.
